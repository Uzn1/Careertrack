# CareerTrack · 커리어 플래너

학업과 취업 준비를 함께 관리하는 Nuxt 4·Vue·TypeScript·Tailwind CSS 웹 앱입니다. 기준 문서는 루트의 [PRD.md](./PRD.md), 작업 규칙은 [codeX.md](./codeX.md)입니다.

## 화면 구성

- **홈**: 오늘 할 일 전체 목록(완료한 일은 아래로 이동·취소선 표시), 프로젝트 현황, 월별·주간 달력. 날짜 칸을 누르면 해당 날짜의 일정이 열립니다.
- **오늘 할 일**: 할 일 / 진행 중 / 완료 3열 보드. 드래그, 수정창의 상태 선택, 완료 체크로 작업을 옮기고 분류별로 확인합니다. 달력은 홈에만 표시합니다.
- **취업 관리**: 기업별 상세 페이지에서 일정·할 일과 자료 보관함을 관리합니다. 항목의 실행일·마감일·완료 상태는 오늘 할 일과 같은 기록을 사용합니다. 자료 보관함에는 메모·링크·10MB 이하 파일을 첨부할 수 있습니다. 종료된 프로젝트는 별도 영역에 보관하고 다시 열 수 있습니다.
- **고정 시간표(선택)**: 홈에서 켜고 끄는 주간 시간표. 요일별 시간 격자에 루틴 블록이 표시되며, 겹치는 루틴은 나란히 표시합니다.
- **주간 우선순위(선택)**: 홈 달력에서 펼쳐 쓰는 주별 최대 3개 입력칸. 사용하지 않아도 됩니다.
- **휴지통**: 카드의 휴지통 아이콘으로 옮긴 할 일을 원래 날짜·상태·연결로 복원합니다.
- **상단 알림**: 내일의 최신 할 일 요약. 별도 브리핑 메뉴는 없습니다.

할 일의 실행 예정일과 제출 마감일은 별도로 저장됩니다. 미루기는 실행 예정일만 바꾸며, 진행 상태· 완료 상태와 프로젝트 연결은 동일 작업으로 공유합니다. 분류는 기본 항목 선택 또는 직접 입력(최대 40자)이 가능합니다.

## 로컬에서 확인

Node.js 22.12 이상을 사용합니다(개발 환경 Node.js 24).

```sh
npm ci
npm run dev:feed
```

| 시안 | 주소 | 실행 명령 |
|---|---|---|
| A · 초록색 카드 피드 | http://localhost:3000 | `npm run dev:feed` |
| B · 짙은 초록색 플래너 | http://localhost:3001 | `npm run dev:calendar` |
| C · 프로젝트 워크스페이스 | http://localhost:3002 | `npm run dev:workspace` |

세 시안은 같은 기능을 제공합니다. Supabase 미설정 시 브라우저 체험 모드로 실행되며, 자료는 접속 주소별로 분리 저장됩니다. 기존 1단계의 할 일은 원본을 보존한 채 이어서 읽습니다. Supabase 설정 후 같은 계정으로 로그인하면 세 시안에서 같은 DB 자료를 조회합니다. 체험 자료는 계정으로 자동 업로드되지 않습니다.

## 검사

```sh
npm test
npm run lint
npm run typecheck
npm run build
```

배포 파일은 각 `apps/<시안>/.output/public`에 생성됩니다. 세 앱의 중간 파일은 서로 분리됩니다. 빌드와 타입 생성은 동시에 실행하지 마세요.

## 연결 상태와 범위

로그인·DB 연동 코드와 사용자별 접근 제한 SQL은 준비되어 있습니다. 실제 Supabase 적용과 Vercel 배포는 계정 연결 후 검증해야 합니다. [터미널 없이 웹에서 연결하는 안내](./docs/SETUP.md)를 참고하세요.

예약 이메일 발송, 휴대폰 위젯, 친구 기능, 자동 단계 전환은 이번 웹 MVP에 포함되지 않습니다. 단계별 결과는 [구현 기록](./docs/IMPLEMENTATION.md)에서 확인할 수 있습니다. 사용자의 업로드 요청에 따라 현재 구현을 GitHub에 반영합니다. AI 호출과 결제 기능은 비활성 상태이며, 그로블은 [연결 준비 안내](./docs/PAYMENTS.md)만 마련했습니다.
