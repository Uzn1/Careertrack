# 다음 · 커리어 플래너

학업과 취업 준비를 함께 관리하는 Nuxt 4 웹 앱입니다. 기능 기준은 [PRD.md](./PRD.md), 작업 규칙은 [codeX.md](./codeX.md)입니다.

## 현재 단계

**1단계: 오늘 할 일.** 등록, 수정, 완료·완료 취소, 우선순위 정렬, 제출 마감일 표시를 제공합니다. 데이터는 이 브라우저에 임시 저장됩니다. 로그인이나 서버 저장은 아직 연결하지 않았습니다.

[전체 5단계 계획과 확인 기준](./docs/IMPLEMENTATION.md)

## 실행

Node.js 22.12 이상(개발 환경: Node.js 24)을 사용합니다.

```sh
npm ci
npm run dev:feed
```

http://localhost:3000 에서 확인합니다. 다른 시안의 기본 화면은 `npm run dev:calendar`(3001), `npm run dev:workspace`(3002)로 실행합니다. 각 주소의 임시 저장 자료는 서로 분리됩니다.

## 1단계 브라우저 확인

1. **할 일 추가**를 눌러 이름, 분류, 우선순위, 제출 마감일을 입력하고 저장합니다.
2. 우선순위가 다른 할 일을 추가합니다. 높은 순위가 먼저 나오며, 같은 순위는 등록 순으로 나옵니다.
3. 할 일 이름을 누르면 수정할 수 있습니다.
4. 왼쪽 체크 버튼을 누르면 **완료한 일**로 이동하며, 다시 누르면 목록으로 돌아옵니다.
5. 페이지를 새로고침해도 작성 내용이 남아 있는지 확인합니다.
6. 모바일 너비에서 할 일과 마감일이 가로 스크롤 없이 보이는지 확인합니다.

## 검사

```sh
npm test
npm run lint
npm run typecheck
npm run build
```

세 앱의 배포 파일은 각각 `apps/<시안>/.output/public`에 생성됩니다. 사용자 확인 전에는 커밋·푸시하지 않으며, Vercel 배포는 5단계에서 진행합니다.
