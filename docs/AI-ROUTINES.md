# 텍스트로 고정 시간표 편집

홈 → 고정 시간표 켜기 → **AI로 편집**에서 `월화수 9:00~10:00에 기출 풀기`처럼 입력합니다. AI 결과는 편집창에 먼저 채워집니다. 요일·시간·활동·색상을 확인하고 **시간표 저장**을 누릅니다. `월요일, 수요일 요가수업 제거해줘`처럼 삭제를 요청할 수도 있습니다. 제거할 요일과 활동을 미리 확인하고 **제거하기**를 눌러 적용합니다. 다른 요일은 유지되며 모든 요일을 제거하면 해당 루틴이 삭제됩니다.

한 번에 활동 하나, 최대 500자까지 입력합니다. 종료 시간만 빠졌다면 해석된 요일·시작 시간·활동을 확인한 뒤 편집창에서 종료 시간을 입력합니다. 요일·시작 시간이 없거나 자정을 넘기는 요청은 다시 입력해야 합니다. AI가 잘못 해석할 수 있으므로 저장 전에 확인하세요. 문장은 OpenRouter와 모델 제공사로 전송됩니다.

## 로컬

루트 `.env`의 `OPENROUTER_API_KEY`를 서버에서 읽습니다. 설정을 바꿨다면 개발 서버를 다시 시작합니다. 로컬 개발 중에는 체험 모드에서도 해석할 수 있습니다. 키 값은 화면·로그에 표시하지 않습니다.

## Vercel

각 프로젝트의 환경변수에 `OPENROUTER_API_KEY`를 비밀 값으로 직접 등록하고 재배포합니다. `NUXT_PUBLIC_`을 붙이지 마세요. 루트 `api/generate-routine.ts`가 Vercel 서버 함수로 실행되며, 화면은 기존 정적 배포를 유지합니다. `apps/*/vercel.json`의 경로 규칙은 API를 정적 화면으로 바꾸지 않습니다.

배포 환경에서는 Supabase 로그인 토큰을 서버에서 검증합니다. Supabase URL·공개 키와 기존 DB 설정도 필요합니다. 비로그인 방문자·체험 사용자는 AI 호출을 할 수 없으며 직접 추가는 가능합니다. API 키만 입력해도 계정 연결이 자동 완료되지는 않습니다.

무료 제공사 응답 장애 시 명확한 요일·24시간제 시각·활동 문장만 기본 규칙으로 정리합니다. 이 경우 편집창에 대체 처리 안내가 표시됩니다. 모호한 지시·부정·복수 활동·밤샘은 기본 규칙으로 추정하지 않습니다. 인증 실패나 키 미설정은 우회하지 않으며, 확인 전 저장·삭제하지 않습니다.

기본은 무료 모델 경로 `openrouter/free`이며 유료 모델로 자동 전환하지 않습니다. 무료 모델 공급·사용량에 따라 실패하거나 지연될 수 있습니다. 실패하면 입력을 유지하고 재시도 또는 직접 추가할 수 있습니다.

공식 안내: [무료 모델 경로](https://openrouter.ai/openrouter/free), [구조화된 응답](https://openrouter.ai/docs/guides/features/structured-outputs).
