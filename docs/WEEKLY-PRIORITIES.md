# 주간 우선순위 확인하기

홈의 **나의 일정 → 주간 우선순위 · 선택**을 누르면 입력칸을 펼칠 수 있습니다. 기본으로 접혀 있으며 사용하지 않아도 됩니다. 주마다 최대 세 개를 작성하고 저장합니다. 기준은 달력과 같은 일요일~토요일입니다.

1. 홈에서 나의 일정까지 내려가 우선순위를 펼칩니다.
2. 한두 칸만 입력하고 저장한 뒤 새로고침합니다. 나머지 칸은 비워 두어도 됩니다.
3. 주간 달력에서 다음 주로 이동해 다른 우선순위를 저장합니다. 이전 주로 돌아와 기록이 따로 남아 있는지 확인합니다.
4. 제목을 다시 눌러 입력칸을 접습니다. 작성한 내용은 삭제되지 않습니다.

기존 월간 우선순위는 주간 기록으로 임의 변환하지 않고 보존합니다. 실제 계정 저장에는 `202611190011_weekly_priorities.sql` 적용이 필요합니다. 현재 로컬 체험 저장만 자동 검사했으며 실제 Supabase 적용은 미검증입니다.
